# Shared test vectors

These inputs come with independently established expected results, and
every implementation (Rust, Rust + Scryer, Bend) is checked against them.
They are generated by

```
cargo run --release --example gen_vectors -- shared/test-vectors
```

Generation is deterministic. Rerunning it MUST leave this directory
byte-identical, and `cargo test --test vectors` checks every entry.

## Layout

```
manifest.tsv            one line per vector (below)
<family>/<id>.prop      formula text (docs/triple-format.md §1), or
<family>/<id>.cnf       DIMACS CNF (§2)
<family>/<id>.tri       triple file of the input, decomposed with sharing (§3)
```

Track A implementations read the `.tri` file. Implementations with their own
parser read the `.prop`/`.cnf` file, and their decomposition must reproduce
the `.tri` file exactly.

## `manifest.tsv` columns (tab-separated; `#` lines are comments)

| Column | Meaning |
|--------|---------|
| `id` | unique vector id |
| `family` | PRD §40 family: `small` (A), `random` (B), `structured` (C), `saturation` (D), `dilemma` (E), `unsat` (F) |
| `generator_version` | `stalmarck::generate::GENERATOR_VERSION` at generation time |
| `seed` | generator seed, or `-` for seedless constructions |
| `params` | generator name and parameters |
| `file` | input path relative to this directory |
| `sha256` | SHA-256 of the input file's bytes (PRD §41) |
| `expected` | `SAT` or `UNSAT` |
| `expected_source` | `oracle` (exhaustive truth table, `stalmarck::oracle`, ≤ 22 variables) or `theory` (true by construction: pigeonhole, parity mismatch, implication chain) |
| `ref_hardness` | smallest Dilemma depth k ≤ 3 at which the **reference Rust solver** refutes the input (sharing on), or `-` for SAT vectors and for UNSAT vectors not refuted within k ≤ 3 and a 200 000-branch budget |

`expected` is independent of every Stålmarck implementation.
`ref_hardness` is *not* independent: it records the reference implementation's
behaviour. By the formal specification (SPEC-K2), every conforming
implementation must refute the vector at exactly that depth.
